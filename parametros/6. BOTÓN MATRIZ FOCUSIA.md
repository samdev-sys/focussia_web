**<mark>6.  BOTÓN MATRIZ. FOCUSIA VERSIÓN 1.0. 2026</mark>** 

# **1. IDENTIFICACIÓN DEL MÓDULO** 

**Nombre funcional:** Botón 6 - Matriz. 

**Tipo de módulo:** educativo completo, breve, interactivo y preparatorio para la planificación. **Ubicación en el flujo principal** : ANUAL -> MENSUAL -> MATRIZ -> KANBAN BACKLOG -> SEMANAL -> DIARIA TIME BLOCKING. 

**Propósito general:** enseñar al usuario a priorizar sus tareas mediante la Matriz de Eisenhower antes de organizar sus acciones reales en Kanban, planificación semanal y agenda diaria. 

# **2. CONTEXTO FUNCIONAL** 

El botón MATRIZ se ubica después del módulo MENSUAL (En el proceso de planificación) porque el usuario ya tendrá aprobadas sus 12 Metas Mensuales. Antes de convertir esas metas en acciones semanales, Focusia debe enseñarle una herramienta simple para decidir qué hacer, qué planificar, qué delegar y qué eliminar. Este módulo no debe sentirse como un curso largo. Debe ser una experiencia educativa corta, clara y accionable, diseñada para que el usuario aprenda la lógica de priorización y luego continúe con su planificación. 

<mark>OJO</mark> La ruta aprobada desde el módulo anterior. 5. MENSUAL cambia: después de aprobar las Metas Mensuales, el botón de salida debe decir “Entender cómo priorizar mis tareas”, y debe llevar al usuario al botón MATRIZ. 

# **3. OBJETIVOS DEL BOTÓN MATRIZ** 

- Explicar la diferencia entre urgente e importante. 

- Presentar la Matriz de Eisenhower como herramienta de priorización. 

- Mostrar los cuatro cuadrantes de forma visual e interactiva. 

- Permitir una práctica breve con cuatro ejemplos simples. 

- Preparar al usuario para ordenar acciones en Kanban Backlog y luego pasar a la planificación semanal y la planificación diaria. 

# **4. FLUJO GENERAL APROBADO** 

1. El usuario ingresa al botón MATRIZ desde el dashboard o desde el botón “Entender cómo priorizar mis tareas” al cerrar el módulo MENSUAL. 

2. Aparece la pregunta inicial: “¿Sabes distinguir lo urgente de lo importante?” 

3. El avatar entrega un mensaje breve que introduce la importancia de priorizar. 

4. Se muestra un video explicativo de 45 segundos. 

5. Luego aparece una Matriz de Eisenhower visual e interactiva. 

6. El usuario puede tocar cada cuadrante para ver una explicación breve. 

7. Focusia muestra una práctica breve con 4 ejemplos simples. 

8. El usuario clasifica esos ejemplos en Hacer, Planificar, Delegar o Eliminar. 

9. Focusia corrige automáticamente la práctica. 

10. Si hay errores, Focusia explica brevemente solo los errores. 

11. Al finalizar, aparece el botón: “Continuar con mi planificación”. 

12. Ese botón lleva al siguiente paso lógico: KANBAN BACKLOG.

# **5. PANTALLA 1: ENTRADA AL MÓDULO** 

# **Pregunta inicial** : **¿Sabes distinguir lo urgente de lo importante?** 

# **Mensaje breve del avatar** 

Antes de organizar tu semana, necesitas aprender a priorizar. No todas las tareas tienen el mismo peso: algunas son urgentes, otras importantes, otras pueden esperar y otras simplemente deben salir de tu camino. 

**Botón de avance** : Ver explicación 

# **6. PANTALLA 2: VIDEO EXPLICATIVO** 

# **Duración aprobada:** 45 segundos. 

**Tono aprobado:** mezcla pedagógica, práctica y motivacional. 

# **Guión sugerido del video:** 

Priorizar no significa hacer más cosas, significa decidir mejor. Muchas personas viven atrapadas apagando incendios, respondiendo urgencias y dejando para después lo verdaderamente importante. La Matriz de Eisenhower te ayuda a ordenar tus tareas en cuatro grupos: Hacer, Planificar, Delegar y Eliminar. Lo urgente e importante se hace ahora. Lo importante, pero no urgente, se planifica. Lo urgente, pero no importante, se delega o reduce. Y lo que no es urgente ni importante debe salir de tu camino. Antes de organizar tu semana, aprenderás a mirar tus acciones con más claridad para avanzar con foco hacia tus metas. 

**Botón de avance** : Continuar 

# **7. PANTALLA 3: MATRIZ VISUAL INTERACTIVA** 

Después del video se debe mostrar una matriz de 4 cuadrantes. Cada cuadrante debe ser clickeable/tocable. Al tocarlo, el usuario ve solo una explicación breve. No se deben mostrar ejemplos largos, consejos adicionales ni botones internos dentro de cada cuadrante. 

|**Cuadrante**|**Criterio**|**Explicación breve al tocar**|
|---|---|---|
|**Hacer**|Urgente e importante|Tareas urgentes e importantes que requieren<br>atención inmediata.|
|**Planificar**|Importante, pero no urgente|Tareas importantes que deben organizarse con<br>tiempo.|
|**Delegar**|Urgente, pero no importante|Tareas urgentes que otra persona podría<br>realizar.|
|**Eliminar**|No urgente y no importante|Tareas que no aportan valor y deben salir del<br>camino.|



# **8. PANTALLA 4: PRÁCTICA BREVE** 

La práctica debe usar 4 ejemplos simples, no tareas reales del usuario ni acciones del Kanban. El objetivo es educar sin presión antes de trabajar con acciones personales. 

# **Instrucción para el usuario** 

Ahora practica con cuatro ejemplos simples. Clasifica cada tarea en Hacer, Planificar, Delegar o Eliminar.

# **9. LÓGICA DE CORRECCIÓN** 

La corrección debe ser automática y breve. Focusia no debe extenderse innecesariamente ni convertir la práctica en una evaluación extensa. 

- Si el usuario clasifica correctamente: mostrar un mensaje breve positivo, por ejemplo “Correcto”. 

- Si el usuario se equivoca: corregir y explicar brevemente solo el error. 

- Si hay más de un error: mostrar cada corrección en una línea breve. 

- Al finalizar: entregar una retroalimentación general de cierre. 

# **Ejemplo de corrección de error** 

Esta tarea corresponde a Planificar, porque es importante, pero no necesita resolverse de inmediato. 

# **Mensaje general de cierre** 

Bien hecho, [nombre]. Ahora ya tienes una base simple para mirar tus acciones con más claridad. El siguiente paso será ordenar tus tareas para convertir tus metas en planificación real. 

# **10. PANTALLA 5: CIERRE DEL MÓDULO** 

Al completar la práctica y recibir la retroalimentación, Focusia debe mostrar el botón final aprobado: 

# **Continuar con mi planificación** 

# Destino del botón: KANBAN BACKLOG. 

Este cierre conecta el aprendizaje de la Matriz de Eisenhower con la organización real de acciones. La lógica no debe saltar directamente a Semanal, porque antes debe existir un espacio para ordenar acciones en Kanban Backlog. 

# **11. REGLAS FUNCIONALES PARA DESARROLLO** 

- MATRIZ es un módulo educativo, no un módulo de planificación completa. 

- No debe crear, modificar ni aprobar metas anuales o mensuales. 

- No debe enviar acciones automáticamente a la agenda diaria. 

- No debe tomar tareas reales del usuario en esta etapa. 

- No debe usar acciones del Kanban para la práctica inicial. 

- Debe enseñar de forma breve, clara y accionable. 

- Debe respetar el principio de Focusia: la aplicación guía, el usuario decide. 

- Debe preparar al usuario para Kanban Backlog, Semanal y Diaria Time Blocking.

# **14. CASOS ESPECIALES** 

# **Usuario abandona el módulo antes de terminar** 

Guardar estado “en progreso”. Al volver, Focusia debe permitir continuar desde la última pantalla relevante o reiniciar el módulo si el usuario lo prefiere. 

# **Usuario ya completó el módulo** 

Si el usuario vuelve a ingresar a MATRIZ, debe poder revisar nuevamente la matriz visual y repetir la práctica si lo desea. El módulo no debe bloquearse, porque funciona también como recurso educativo consultable. 

# **Usuario se equivoca en todos los ejemplos** 

Focusia debe corregir con tono amable, sin juicio. La retroalimentación debe enseñar brevemente y permitir continuar.
