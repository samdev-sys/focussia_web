🚨 RECOMENDACIONES URGENTES (Priorización)
================================================================================

CRÍTICA - Bloquea MVP (Semana 1-2)
─────────────────────────────────────

1. Crear modelo "MetaAnual"
   - Campos: nombre, descripción, fecha_fin, usuario
   
2. Crear modelo "ObjetivoMensual"
   - Campos: meta_anual_fk, mes, descripción
   - 12 registros/año por usuario
   
3. Crear modelo "AccionDiaria"
   - Campos: objetivo_mensual_fk, fecha, descripción, completada
   
4. Implementar API de cascada
   - GET/POST /meta-anual/
   - GET/POST /objetivos-mensuales/
   - GET/POST /acciones-diarias/
   
5. Crear flujo de onboarding
   - Captura Meta Anual
   - Dividir automáticamente en 12 meses
   - Asignar primeras acciones del mes

ALTA - Cierra brecha principal (Semana 2-3)
──────────────────────────────────────────

6. Implementar "Enfoque Hoy" real
   - Meta Anual + Objetivo Mes + 3 Acciones Hoy
   
7. Crear panel "Progreso Estratégico"
   - Visual % anual
   - Conexión cascada visible
   
8. Vincular Gamificación a objetivos
   - XP solo si acción contribuye a meta
   - Mostrar impacto en progreso anual
   
9. Implementar Compañero Estratégico básico
   - Alertas de desviación
   - Sugerencias contextuales

MEDIA - Completa experiencia (Semana 3-4)

    - Videos 2-3 min antes de primera acción
